# Available translations by language

All **1,260 translations** in **1,004 languages** offered by the [Free Use Bible API](https://bible.helloao.org/), and the ID to use with this page.

Use the ID in the `translation` parameter, exactly as shown (IDs are case-sensitive):

```
https://ikelaiah.github.io/verse-of-the-day/?translation=eng_gnv
```

> Generated on 2026-10-13 from the API's [translation list](https://bible.helloao.org/api/available_translations.json). The API adds translations over time, so check that link for the latest list.

## Columns

| Column | Meaning |
|---|---|
| **ID** | Value for `?translation=` |
| **Books** | Number of books included: 66 = whole Bible, 27 = New Testament only, fewer = portions. If the day's verse is in a missing book, the page falls back to OurManna's NIV. |
| **Licence** | **Public domain**: free to use. **© notice shown**: copyrighted, and the page shows the publisher's notice automatically. **Credit required**: the translator must be credited, but the page only shows the translation's name, which may not be enough. **Non-commercial**: not for commercial use. **Unknown**: no licence data in the API, so check the source. The link opens the licence or source page. |
